# 모델과 평가지표 추가 검증: 1차 결과

작성: 반서윤 (데이터팀) · 작성일: 2026-10-04
관련 파일: 관련 파일: `scripts/model/evaluate_models.py`(평가 코드), `docs/model/eval-summary.csv`(8개 모델 지표 요약)

## 요약

- 8개 모델(기존 4개 + ExtraTrees, XGBoost, LightGBM, CatBoost)을 같은 분할·특징·CPU 조건으로 평가했다.
- **Macro F1 1위는 CatBoost(0.2568)** 로 2위 LR(0.2307)보다 0.026 높다. 단일 분할 결과이므로 1위로 단정하지 않는다.
- ExtraTrees는 Accuracy 1위(0.4028)지만 Macro F1은 최하위(0.1795, Dummy 제외)로, 다수 클래스에 성능이 몰린 사례다.
- 혼동은 대부분 같은 대분류(1.x끼리, 베타 계열끼리, 3.x끼리) 안에서 일어난다.
- 보조 지표는 **Balanced Accuracy**를 제안한다. Weighted F1은 다수 클래스 쏠림 확인용으로 함께 둔다.

## 기존 Excel(v1)과 수치가 다른 이유

v1 이후 데이터가 업데이트되었다. 원본 구조 오류 샘플 등이 제외되어 학습 데이터가 21,568건에서 **21,545건**으로, 분할은 fit 17,252 / validation 4,316에서 **17,238 / 4,307**로 바뀌었다(데이터 커밋 `0defd1e` → `797d114`). 이에 따라 LR Macro F1이 0.2408에서 0.2307로 바뀌었다. 새 데이터에서 `baseline.py`도 0.23070을 내며, 새 평가 코드의 LR·RF·HGB 결과는 기존 비교 코드와 소수 다섯째 자리까지 같다.

관찰:

- **Balanced Accuracy와 Macro Recall은 모든 모델에서 같다.** 검증 데이터에 20개 클래스가 모두 있어 정의상 같은 값이 된다.
- **Weighted F1 − Macro F1 차이**는 LR 0.064, CatBoost 0.108, HGB 0.109, RF 0.120, LightGBM 0.132, XGBoost 0.138, ExtraTrees 0.169 순으로 커진다. 차이가 클수록 다수 클래스에 성능이 몰려 있다.
- 차이가 가장 큰 ExtraTrees를 클래스별로 보면, 3.40을 1,615건(실제 921건), 3.30을 916건(667건), 1.10을 871건(649건) 예측해 전체 예측의 약 79%가 큰 세 클래스에 몰렸다. 20개 중 8개 클래스는 F1 0이며, 3.90은 실제 218건이지만 한 번도 예측하지 않았다. 그래서 Accuracy는 가장 높지만 Macro F1은 가장 낮다(Dummy 제외).
- ExtraTrees(1,586MB)와 RF(512MB)는 모델 크기가 제출 ZIP 상한 500MB에 걸리거나 근접한다.
- CatBoost는 학습시간이 LR의 약 100배다. 추론은 샘플당 0.003ms로 빠르다.
- 추론 시간은 모든 모델이 샘플당 0.08ms 미만으로, 평가 데이터 5,387건 기준 1초 이내라 추론 10분 상한에는 영향이 없다.

## 2. 상위 모델의 클래스별 강점·약점

Macro F1 상위 3개 모델 기준이다. 전체 20개 클래스 표는 Excel "클래스별 F1" 시트와 ZIP의 `per_class/`에 있다.

**CatBoost (Macro F1 0.2568)**
- 강점: 큰 클래스(1.10, 1.20, 2.60, 3.40)에서 F1 0.47~0.50으로 고르다. 예측 건수가 실제 건수와 비슷한 클래스가 많다(1.10 실제 649 / 예측 658, 1.20 306 / 309, 2.70 30 / 29). 다른 모델이 놓치는 2.70(0.31), 4.10(0.21)도 일부 잡는다.
- 약점: 2.170은 12건을 예측했지만 모두 틀려 F1 0이다. 3.50(0.02), 2.20(0.08)도 거의 맞히지 못한다.

**Logistic Regression (Macro F1 0.2307, Balanced Accuracy 1위)**
- 강점: 2.160 F1 0.41로 세 모델 중 압도적이다(CatBoost 0.17, RF 0). 2.10 재현율 0.88.
- 약점: 작은 클래스를 과다 예측한다(2.170 실제 20 / 예측 167, 3.60 42 / 301, 3.50 27 / 240). 반대로 큰 클래스는 과소 예측한다(3.40 실제 921 / 예측 398, 3.30 667 / 243, 3.30 재현율 0.09). 그래서 Balanced Accuracy는 높지만 Accuracy와 Weighted F1은 낮다.

**Random Forest (Macro F1 0.2266)**
- 강점: 3.40(0.52), 3.20(0.46), 6.10(0.46)에서 세 모델 중 가장 높다.
- 약점: 작은 클래스를 거의 예측하지 않는다. 2.160(예측 2건), 2.170(7건), 3.50이 F1 0이다.

**세 모델 모두 어려운 클래스**: 2.170, 3.50, 2.20, 3.10, 3.60, 2.30, 3.90 (F1 0.15 이하). 이 중 3.10(172건), 2.30(137건), 3.90(218건)은 작은 클래스가 아니므로, 건수보다 31개 특징으로 구분하기 어려운 것이 원인으로 보인다.

## 3. 반복 혼동 (CatBoost Confusion Matrix)

| 실제 → 예측 | 건수 | 실제 클래스 중 비율 |
|---|---:|---:|
| 3.50 → 3.40 | 14 | 52% |
| 3.60 → 3.40 | 18 | 43% |
| 2.160 → 2.40 | 14 | 36% |
| 3.90 → 3.40 | 76 | 35% |
| 2.20 → 2.10 | 8 | 32% |
| 2.30 → 3.30 | 41 | 30% |
| 3.10 → 3.30 | 41 | 24% |
| 3.20 → 3.60 | 34 | 22% |
| 1.20 → 1.10 | 65 | 21% |
| 1.10 → 3.30 | 106 | 16% |

패턴:

1. **가장 큰 3.40이 비슷한 3.x 클래스를 흡수한다.** 3.50·3.60·3.90의 35~52%가 3.40으로 예측된다. 3.40 자체도 3.20(93), 3.30(84), 3.60(63), 3.90(61)으로 흩어진다.
2. **1.10 ↔ 3.30 양방향 혼동**(106 / 92건), **3.30 ↔ 3.40**(96 / 84건). 3.30은 667건 중 139건만 맞고 여러 클래스로 흩어진다.
3. **알파 위주 클래스끼리 혼동**: 1.10 ↔ 1.20(55 / 65건), 1.25는 정답(19)보다 1.20(18)+1.10(16)으로 간 경우가 많다. 6.10도 1.10·1.20으로 간다.
4. **베타가 많은 클래스끼리 혼동**: 2.30·2.40·2.60·3.10 사이(예: 2.60 → 3.10 53건, 2.60 → 2.40 46건, 3.10 → 2.30 28건).
5. **작은 클래스가 비슷한 큰 클래스로 흡수**: 2.160 → 2.40, 2.20 → 2.10, 2.170은 정답 0건.

정리: 혼동 대부분이 같은 대분류 안에서 일어난다. 31개 특징이 아미노산 구성과 전체 모양은 반영하지만, 구조 요소가 어떻게 배열·연결되는지는 잘 구분하지 못하는 것으로 보인다.

## 4. 보조 지표 선정

공식 순위는 Macro F1로 보고, 보조 지표로 **Balanced Accuracy**를 함께 제시한다. Accuracy나 Weighted F1을 기준으로 하면 Macro F1 최하위인 ExtraTrees(Accuracy 0.4028)가 1위가 되어 클래스 균형이라는 대회 목표와 반대 방향을 가리킨다. 다만 Balanced Accuracy(= Macro Recall)는 LR처럼 작은 클래스를 과다 예측해도 높아지므로 Macro F1과 함께 해석하고, Weighted F1은 다수 클래스 쏠림을 확인하는 참고 열로 둔다.
