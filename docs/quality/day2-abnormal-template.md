# Day 2 비정상 값 점검 양식

점검표(C-01 ~ C-14)의 규칙은 통과했지만 값이 유난히 튀는 샘플을 찾아 기록하는 양식이다. 원본 데이터는 수정하지 않는다.

비정상 값의 기준은 문서에 없다. 항목마다 점검자가 기준을 정하고, 정한 이유를 함께 적는다.

## ① 개요 (점검할 때 채움)

| 항목 | 내용 |
| --- | --- |
| 점검자 | |
| 점검일 | |
| 데이터 버전 | `admin-2026-protein-data` 커밋 |
| 대상 | 학습 / 평가 중 선택 |
| 관련 문서 | `day1-checklist-template.md`, `day1-report.md` |

## ② 표기 규칙

| 칸 | 값 | 뜻 |
| --- | --- | --- |
| 기준 종류 | 물리 | 실제 단백질에서 불가능한 값 (예: 원자끼리 겹침) |
| | 통계 | 분포에서 극단에 있는 값 (예: 상위 1%, 평균 ± 3표준편차 밖) |
| 판정 | 오류 | 데이터가 잘못 만들어짐. ④ 샘플 기록에 적고 문제 기록(P-xx)으로 넘김 |
| | 특이하지만 정상 | 단백질이 원래 특이함. 학습·평가에 똑같이 있으면 문제 아님 |
| | 미확인 | 오류인지 정상인지 아직 판단 근거가 없음 |

## ③ 점검 항목

| 번호 | 대상 | 무엇을 보나 | 관련 점검표 | 기준 종류 | 기준 | 기준을 정한 이유 | 걸린 샘플 수 | 판정 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| A-01 | 서열 길이 | 분포의 긴 꼬리, 클래스별 길이 차이 | C-13 | 통계 | 서열 길이 ≥ 417 | 학습 데이터 상위 1% 경계값 (평균 151, 중앙값 127) | | |
| A-02 | 아미노산 비율 (`aa_*`) | 한 글자가 서열의 큰 비율을 차지하는 쏠린 서열 | C-10 | 통계 | 가장 많은 한 글자의 비율 ≥ 50% | 상위 1%가 21.8%, 상위 0.1%가 26.8%라서 50%는 분포에서 크게 벗어난 값이다 | | |
| A-03 | 회전 반경 vs 길이 | 같은 길이에 비해 회전 반경이 유난히 큰 구조 | C-10 | 통계 | 회전 반경 ÷ 기대값 ≥ 2 (기대값 = 3.91 × 길이^0.277 Å, 학습 데이터 회귀식) | 같은 길이의 보통 구조보다 두 배 퍼진 구조. 상위 1% 경계(1.98)와 거의 같다 | | |
| A-04 | 모양 (`shape_1`) | 1에 가까운 극단적인 막대형 | C-10 | 통계 | `shape_1` ≥ 0.95 | 중앙값 0.54, 상위 1% 경계 0.958. 한 방향이 전체 퍼짐의 95% 이상인 막대형 | | |
| A-05 | 이웃 Cα 거리 하한 | 같은 구간 안에서 이웃 거리가 너무 짧은 곳 | C-12 | 물리 | 같은 구간 안 이웃 Cα 거리 < 2.7Å | 정상 cis 결합은 약 2.9Å(학습 데이터 3.3Å 미만 8,383쌍의 중앙값 2.95Å, 72%가 프롤린 앞). 분포가 2.75Å부터 급격히 줄어들어 2.7Å 미만은 cis 분포에서 벗어난 값으로 본다 | | |
| A-06 | 원자끼리 겹침 | 이웃이 아닌 Cα끼리 너무 가까운 곳 | 없음 | 물리 | 사슬에서 3칸 이상 떨어진 Cα끼리 최소 거리 < 3.0Å | 이웃이 아닌 Cα는 서로 밀어내서 약 3.8Å 아래로 거의 붙지 않는다(학습 데이터 중앙값 4.0Å). 3.0Å 미만은 물리적으로 설명하기 어렵다 | | |
| A-07 | 좌표 크기 | 중심에서 가장 먼 원자까지의 거리 | C-02 | 통계 | 중심에서 가장 먼 Cα까지 거리 ≥ 87Å | 학습 데이터 상위 0.1% 경계값 (중앙값 26Å) | | |
| A-08 | 구간 개수 | segment가 지나치게 많은 구조 | C-12 | 통계 | 구간 수 ≥ 9 | 학습 데이터 상위 0.1% 경계값 (66%가 1구간) | | |

점검하지 않기로 한 항목은 판정 칸에 "점검 안 함"과 이유를 적는다.

### 칸 작성법

| 칸 | 적는 내용 |
| --- | --- |
| 번호 | 항목별로 `A-01-1`, `A-01-2`처럼 |
| 점검 항목 | ③의 번호 |
| 샘플 ID | `TRAIN_xxxxxx` 또는 `TEST_xxxxxx` |
| label | 문자열 그대로 (`2.30`, `2.160`) |
| 값 | 기준에 걸린 실제 값과 단위 (예: `2.1 Å`, `1,031`) |
| 기준 | ③에서 정한 기준 |
| 확인 방법 | 값만 봤는지, 3D로 봤는지, 원본 PDB와 대조했는지 |
| 판정 | 오류 / 특이하지만 정상 / 미확인 |
| 판정 이유 | 왜 그렇게 판단했는지 한 줄 |
| 문제 기록 | 오류면 `day1-report.md` 문제 기록에 이어서 붙인 P 번호. 아니면 비움 |
