## 안전하다고 확인한 것

행·ID 순서와 정답·Public/Private 관계 없음, zip 파일 시간·순서 정보 정리됨, 평가 분포 통계 비공개(PR #13), 채점 컨테이너 격리(네트워크 없음·읽기 전용·정답 미전달), 예제 파일은 모두 학습 샘플, 공개 파일에 평가 ID·원본 이름 없음.

평가 데이터의 정답, Public/Private 구분, 원본 domain · 단백질 이름은 이 문서에 적지 않았습니다.
