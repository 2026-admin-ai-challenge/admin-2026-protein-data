### 1. 구간 번호(segment_index)가 멀쩡한 사슬을 끊긴 것으로 기록하는 문제

| 항목 | 내용 |
| --- | --- |
| 위치 | `consecutive()` (23~31번째 줄) |
| 무엇이 문제인가 | 원본 PDB 번호가 `4P, 5P, 6P …`처럼 모든 번호에 같은 알파벳을 붙인 경우를 "번호가 이어지지 않음"으로 판단한다. 실제로는 3.8Å 간격으로 정상 연결된 사슬이 칸마다 끊긴 것으로 기록된다 |
| 영향받는 샘플 | 학습 7개 구조(372곳), 평가 1개 구조(94곳) |
| 영향받는 곳 | segment_index로 이웃을 잇는 참가자(그래프 모델 등). 기본 특징 31개와 베이스라인은 segment_index를 쓰지 않아 영향 없음 |
| 고치는 방향 | 번호가 +1이고 앞뒤 알파벳이 같으면 연속으로 인정 |

### 2. 두 위치로 기록된 원자를 섞어서 고르는 경우

| 항목 | 내용 |
| --- | --- |
| 위치 | 대체 위치 선택 (50~54번째 줄) |
| 무엇이 문제인가 | 원본에는 한 부분이 두 가지 모양(A·B)으로 기록되는 경우가 있다. 코드가 잔기마다 따로 점유율이 높은 쪽을 고르다 보니 한 잔기는 A, 옆 잔기는 B가 뽑혀 서로 다른 모양이 섞일 수 있다 |
| 영향받는 샘플 | 확인된 것 1개(TRAIN_020408: 섞인 결과 원자 두 개가 2.56Å로 겹침. 같은 모양끼리는 4.2Å로 정상). 섞였지만 겹칠 만큼은 아닌 구조가 더 있는지는 조사하지 않음 |
| 영향받는 곳 | 좌표를 쓰는 모든 계산(기본 특징 중 거리·모양 값 포함). 섞인 구조에서만 |
| 고치는 방향 | 잔기마다가 아니라 구조 전체에서 한 위치(A 또는 B)로 통일해 고름 |

## ⑤ 참고: 문제는 아니지만 알아둘 것

- **NMR 끝 꼬리 5개 구조:** 사슬 끝부분이 몸통에서 떨어져 길게 뻗어 있다. 용액 속에서 흔들리는 꼬리가 한 자세로 기록된 실험 흔적이다. 회전 반경·모양 같은 특징 값을 크게 만들지만 학습과 평가에 같은 방식으로 들어 있어 공정성 문제는 아님.
