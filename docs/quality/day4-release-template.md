# 배포 점검 양식

참가자에게 나가는 파일과 정보에 숨김 평가 자료가 섞여 있지 않은지 점검하는 양식이다. 배포 후보가 바뀌거나 데이터를 다시 만들 때마다 같은 순서로 점검한다. 파일과 서버 설정은 읽기만 한다.

## ① 개요 (점검할 때 채움)

| 항목 | 내용 |
| --- | --- |
| 점검자 | |
| 점검일 | |
| 기준 문서 | 웹사이트 레포 `docs/participant-release-candidates.md` (커밋) |
| 데이터 버전 | `admin-2026-protein-data` 커밋, `data/DATA_VERSION.json` 건수 |
| 웹사이트 버전 | `admin-2026-protein-structure-challenge` 커밋 |
| 점검 대상 | 배포 후보 ZIP / `data/public/` / 공개 API 응답 중 무엇을 봤는지 |

## ② 표기 규칙

| 판정 | 뜻 |
| --- | --- |
| 통과 | 기준 문서대로이고 숨김 자료가 없음 |
| 위반 | 기준 문서의 공개 금지 대상이 공개 경로에 있음. 고쳐야 함 |
| 불일치 | 숨김 자료는 아니지만 기준 문서와 실제가 다름 (목록에 없는 파일, 숫자 차이 등) |
| 미확정 | 기준 문서가 "확정 필요"로 남겨 둔 항목 |
| 점검 불가 | 대상 파일이 아직 없음 (예: 배포 ZIP 미제작) |

평가 데이터의 정답, Public/Private 구분, 원본 domain · 단백질 이름은 보고서에 적지 않는다.

## ③ 점검 항목

### 허용 목록 대조

| 번호 | 무엇을 보나 | 기준 | 방법 | 결과 | 판정 |
| --- | --- | --- | --- | --- | --- |
| B-01 | 배포 후보 트리의 파일이 모두 있나 | 기준 문서 1절 트리 | 배포 ZIP(없으면 `data/public/`) 파일 목록과 대조 | | |
| B-02 | 트리에 없는 파일이 공개 경로에 있나 | 허용 목록에 없는 파일 0 | 배포 ZIP · `data/public/` · 웹사이트 `PUBLIC_FILES` 대조 | | |
| B-03 | 문서의 숫자·파일 이름이 현재 데이터와 맞나 | 건수, 파일 이름 일치 | `DATA_VERSION.json`, 실제 파일과 대조 | | |

### 공개 금지 대상 (기준 문서 3절)

| 번호 | 금지 대상 | 확인 방법 | 결과 | 판정 |
| --- | --- | --- | --- | --- |
| B-04 | 실제 평가 입력 (`test.csv`, `test_features.csv`, `test_structures.zip`) | 파일 이름, zip 안쪽(중첩 zip 포함), 평가 서열·ID가 공개 CSV에 있는지 | | |
| B-05 | 숨긴 평가 정답 | `labels.csv` 등 파일 이름, 평가 ID와 라벨 쌍이 공개 파일에 있는지 | | |
| B-06 | 평가 Public/Private 분할, 분할을 재구성할 수 있는 설정·seed | partition 열, ID별 분할, seed · 분할 비율 등 설정값이 공개 파일·API에 있는지 | | |
| B-07 | 평가 ID, 원본 식별자 매핑 | `TEST_` ID, 원본 CATH/PDB/domain 이름이 공개 파일·코드·문서에 있는지 | | |
| B-08 | scoring 내부 자료 | 채점 설정·스크립트·중간 결과·숨긴 예측이 공개 경로에 있는지 | | |
| B-09 | 운영 전용 자료·비밀정보 | `.env`, 계정, 토큰, 원본 캐시, 운영진용 README 등이 공개 경로에 있는지 | | |

### 내용 검사

| 번호 | 무엇을 보나 | 기준 | 결과 | 판정 |
| --- | --- | --- | --- | --- |
| B-10 | 공개 예제 | 예제 ID가 학습 샘플이고 평가 ID와 겹치지 않음. 입력에 정답 열 없음. 예제 출력 라벨이 공개 학습 라벨과 같음 | | |
| B-11 | CSV 열 · NPZ 키 | 공개 CSV 열과 NPZ 배열 키가 문서 규격과 같고 추가 열·키 없음 | | |
| B-12 | 코드 · 문서 · 노트북 | 평가 자료를 가리키는 하드코딩 값, 노트북 실행 결과, 비공개 경로가 없음. 서버 전용 파일 이름을 설명하는 문장은 허용 | | |
| B-13 | 공개 API 메타데이터 | 로그인 없이 받는 API 응답(`/api/competition` 등)에 B-04 ~ B-09 대상이 없음 | | |

### ML 대회 취약점

데이터 쪽 항목(B-04 ~ B-07, B-10, B-11, V-01 ~ V-03, V-08)은 `scripts/quality/day4_release_checks.py`로 계산한다. 웹사이트 항목은 코드를 읽고 근거 파일 위치를 적는다.

| 번호 | 취약점 | 확인 방법 | 결과 | 판정 |
| --- | --- | --- | --- | --- |
| V-01 | 행 · ID 순서 누출 | ID 순서 구간과 라벨 · Public/Private의 카이제곱 검정, 이웃 같은 라벨 비율 | | |
| V-02 | 파일 메타데이터 | zip 안 파일 시간 · 순서 · 주석 · 추가 정보 | | |
| V-03 | 파일 크기 | 클래스별 압축 크기 ÷ 길이 | | |
| V-04 | 중복 · 유사 샘플 | 품질 보고서 E-04 · E-06 | | |
| V-05 | 공개 원본 DB로 정답 역추적 | 생성 규칙, 참가자 규칙, 재현 검증 기준 | | |
| V-06 | 외부 사전학습 모델 | 허용 범위 규칙 | | |
| V-07 | 분할 설정 · seed 공개 | B-06과 같음 | | |
| V-08 | 평가 분포 통계 | 공개 metadata로 평가 개수 계산 가능 여부 | | |
| V-09 | 오류 메시지 · 로그 | 참가자에게 보이는 실패 안내 · 검사 결과 · 시각에 참가자 코드가 고를 수 있는 값이 있는지 | | |
| V-10 | 리더보드 탐색 | Public 비율, 제출 횟수, 실패 차감 | | |
| V-11 | 채점 환경 격리 | 네트워크, 마운트, 권한, 정답 · 분할 미전달 | | |
| V-12 | 채점 중 패키지 설치 | 설치 단계에 제출 코드 · 평가 입력이 붙는지, 네트워크 범위 | | |
| V-13 | 저장소 · git 기록 | 레포 공개 범위, git에 들어 있는 비공개 자료 | | |
