# Day 3 평가 데이터 점검 보고서

Day 1·2에서 학습 데이터에 적용한 점검을 평가 데이터에 그대로 적용한 결과다. Day 3에서 찾은 문제(N-01, D-01, P-30 잔여, 알라닌 부분 채움)도 함께 확인했다. 원본 데이터는 읽기만 했다.

평가 데이터의 정답(label)과 Public/Private 구분, 원본 domain·단백질 이름은 이 문서에 적지 않는다. 이름만으로도 CATH에서 정답을 찾을 수 있기 때문이다.

### 왜 했나

1차 점검은 학습 데이터 기준이었고, 평가 데이터는 C-06(학습/평가 겹침)과 C-12(구간 번호)만 확인했다. PR #5는 원본 오류를 **샘플 목록으로 제외**했는데, 이 목록은 학습 데이터 점검 결과로만 만들어졌다.

| 고친 방식 | 평가 데이터에 적용되나 |
| --- | --- |
| 생성 코드 수정 (구간 번호, 모양 선택, 겹침 필터) | 같은 코드가 평가 데이터도 만들므로 자동 적용 |
| 샘플 목록으로 제외 (`quality_exclusions.csv`) | 점검한 샘플에만 적용. 평가 데이터는 빈틈 |
